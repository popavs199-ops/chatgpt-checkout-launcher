ChatGPT Checkout Launcher

Three ways to run the script on chatgpt.com. Pick the one that matches how much setup you want.

One-time setup needed: The hosted script file is currently a placeholder. To finish setup, paste your obfuscated script body into chatgpt-checkout.user.js on GitHub. Open the file editor →

Option 1 — Tampermonkey Recommended

Install once, the script auto-runs every time you visit chatgpt.com. Most reliable way.

  1. Install the Tampermonkey browser extension: tampermonkey.net
  2. Click the install button below — Tampermonkey will pop up and ask you to confirm.
  3. Visit chatgpt.com. The buttons appear automatically.
Install via Tampermonkey

Option 2 — Paste in DevTools console

No install. You paste the script manually each time you want to use it.

  1. Click Copy script below.
  2. Click Open ChatGPT — opens chatgpt.com in a new tab.
  3. On chatgpt.com, press F12 (or Cmd+Option+I on Mac) to open DevTools.
  4. Click the Console tab.
  5. If Chrome shows a "self-XSS" warning, type allow pasting and press Enter once.
  6. Paste with Ctrl+V and press Enter.
Open ChatGPT

Option 3 — Bookmarklet

Drag the button below to your browser's bookmarks bar. Then visit chatgpt.com and click the bookmark to inject the script.

  • Show the bookmarks bar first if it's hidden (Ctrl+Shift+B).
  • Drag this button up to your bookmarks bar:
🔗 ChatGPT Launcher

Then on chatgpt.com just click the bookmark.
